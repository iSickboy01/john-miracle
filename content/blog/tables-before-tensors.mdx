If the outcome is a count, start with a table. If the features are a few clinical variables, start with a GLM in R. NumPy and pandas are for the mess in the middle: dates that lie, missingness that is informative, units that nobody documented.

TensorFlow is a tool for a different shape of problem. Using it as a personality trait is how you get a model that cannot survive a methods grilling.
